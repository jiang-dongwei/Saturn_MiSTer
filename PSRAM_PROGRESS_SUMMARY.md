# Saturn PSRAM Integration Progress / Saturn PSRAM 集成进度

The Sega Saturn core now uses the external QPI PSRAM as its RAMH memory: standalone diagnostics and stress tests pass, the full core runs games at approximately 28.64 MHz with a 16-byte read cache, and external-interface timing analysis now passes with positive margins, leaving only one final hardware regression before release.

Sega Saturn Core 现已将外接 QPI PSRAM 作为 RAMH 使用：独立诊断和压力测试已经通过，完整 Core 以约 28.64 MHz 和 16 字节读取缓存成功运行游戏，外部接口时序分析也已取得全部正裕量，目前只剩一次最终真机回归，完成后即可进入发布阶段。
